# Indeks Referensi

Salinan lokal setiap sumber yang dikutip di naskah. Satu sumber = satu file, dinamai `PenulisPertama_Tahun_KataKunci.pdf`.

Status: **Teks penuh** = naskah lengkap; **Abstrak** = hanya halaman abstrak/deskripsi; **Belum** = belum terunduh.

Urutan cara unduh: `curl` → salinan *open access* via OpenAlex (`https://api.openalex.org/works/doi:<DOI>`, kolom `locations[].pdf_url`) → Playwright → minta pengguna mengunduh manual.
